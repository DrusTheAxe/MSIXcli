# Privacy Policy for MSIXcli

_Last Updated: August 24, 2026_

## Overview

MSIXcli does not collect, store, transmit, process, or share any personal information.

The application runs entirely on the user's device and does not communicate with external services.

## Data Collection

MSIXcli does not:

- Collect personal information
- Create user accounts
- Require user registration
- Use analytics or telemetry services
- Track user activity
- Display advertising
- Share information with third parties

## Data Storage

MSIXcli does not store personal information.

## Third-Party Services

MSIXcli does not use third-party services that collect or process user information.

## Changes to This Policy

If future versions of MSIXcli introduce features that collect or process personal information, this Privacy Policy will be updated accordingly.
